# 实施计划：添加"我的文件"页面（简易网盘功能）

## Context

用户需要在导航菜单中新增一个"我的文件"页面，实现简易网盘功能：支持文件上传（最大 200MB）、下载、删除，按用户隔离。项目使用 Vue 3 + Element Plus 前端 + Express 5 + better-sqlite3 后端，无现成文件上传中间件，需安装 multer。

## 详细实施步骤

### Step 1: 安装 multer

```bash
npm install multer @types/multer
```

### Step 2: 数据库 - 新增 `user_files` 表

在 `src/config/database.ts` 中添加：

```sql
CREATE TABLE IF NOT EXISTS user_files (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id INTEGER NOT NULL,
  original_name TEXT NOT NULL,
  stored_name TEXT NOT NULL,
  mime_type TEXT,
  file_size INTEGER NOT NULL,
  created_at TEXT DEFAULT (datetime('now', 'localtime')),
  FOREIGN KEY (user_id) REFERENCES users(id)
)
```

导出 CRUD 函数：
- `getUserFilesList(userId)` - 列出用户所有文件
- `getUserFileById(id, userId)` - 获取单个文件元数据
- `createUserFile(originalName, storedName, mimeType, fileSize, userId)` - 创建记录
- `deleteUserFile(id, userId)` - 删除记录

### Step 3: 后端路由 `src/routes/userFiles.ts`

- `GET /api/user-files` - 获取文件列表
- `POST /api/user-files/upload` - 上传文件（multer 单文件，字段名 `file`，限制 200MB）
- `GET /api/user-files/:id/download` - 下载文件（返回原始文件名）
- `DELETE /api/user-files/:id` - 删除文件（同时删除磁盘文件和数据库记录）

文件存储路径：`~/.models-manager/user-files/{userId}/`，使用 `crypto.randomUUID()` 作为存储文件名避免冲突。

### Step 4: 挂载路由

在 `src/app.ts` 中：
- 导入并挂载 `userFilesRouter` 到 `/api/user-files`
- 添加 `/files` 的 SPA fallback 路由

### Step 5: 前端 API 层

新建 `frontend/src/api/userFilesService.ts`：
- `getUserFiles()` - 获取列表
- `uploadFile(file: File)` - FormData 上传
- `downloadFile(id: number)` - 下载（返回 blob URL）
- `deleteFile(id: number)` - 删除

### Step 6: 前端 PC 页面 `FilesPage.vue`

使用 Element Plus 组件：
- `el-upload` 组件实现拖拽上传，限制 200MB，支持多文件
- `el-table` 展示文件列表（文件名、大小、上传时间、操作）
- 操作列：下载、删除按钮
- 文件大小格式化为 human-readable

### Step 7: 更新导航

在 `HomePage.vue`、`MemoryPage.vue` 的导航栏中各加一个按钮：
```html
<el-button :type="currentNav === 'files' ? 'primary' : 'text'" @click="handleNavSelect('files')">
  <el-icon><FolderOpened /></el-icon> 我的文件
</el-button>
```

`handleNavSelect` 中增加 `files` 分支，路由到 `/files`。

### Step 8: 前端路由

PC: `frontend/src/router/index.ts` 添加：
```ts
{ path: '/files', name: 'Files', component: () => import('@/views/FilesPage.vue'), meta: { requiresAuth: true } }
```

Mobile: `frontend/src/mobile/router/index.ts` 添加：
```ts
{ path: '/m/files', name: 'MobileFiles', component: () => import('../views/FilesPage.vue'), meta: { requiresAuth: true } }
```

### Step 9: 移动端页面

新建 `frontend/src/mobile/views/FilesPage.vue`，使用 Vant 组件，在 mobile HomePage.vue 添加"文件"导航按钮。

## 关键设计决策

1. **文件存储**：磁盘文件存放在 `~/.models-manager/user-files/{userId}/`，按用户隔离
2. **文件名处理**：上传时用 UUID 重命名存储，数据库保留原始文件名用于显示和下载
3. **200MB 限制**：multer `limits.fileSize` 设置 + 前端 `el-upload` 的 `:before-upload` 校验
4. **下载安全**：通过 API 路由下载，需要登录态（X-Username header），不直接暴露静态路径
5. **不创建共享 layout**：遵循现有模式，每个页面各自复制导航栏（虽然不优雅，但保持一致性）
